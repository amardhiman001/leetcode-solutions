This repository contains my solutions to LeetCode problems, organized by problem number and name. Each folder includes the problem statement, my solution in the language I solved it in, and notes on my approach along with time and space complexity where relevant. Solutions are automatically synced from LeetCode using LeetHub as I solve new problems.

I'm using this repo to track my progress on data structures and algorithms, and to build a searchable reference I can revisit when practicing for interviews.
